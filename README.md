# Azeramus – Audio Contributions

A snapshot of my contributions as **Technical Sound Designer** to the game 
project **Azeramus** (First Impact Studios), 2023.

## My Role

Creation and implementation of SFX for the game, using FMOD and Unity.

## Main Contributions (Dec 2023)

### UI Sounds
- Menu open/close
- Button click and hover
- Tab open/close
- Game start

### Gameplay Sounds
- Ability activation / not charged / not valid
- Board destroyed / board summon
- Card interactions (drag, drop, hover, select)
- Battle sounds (Assan Card, Belshassar Card, Enemy Turn, Hide/Show Rule, 
Nightmare Expansion, Player Turn)

## Files

All audio files are in `Azeramus/Assets/New SFX/`.
